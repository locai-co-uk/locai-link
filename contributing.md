# Contributing to Loc.ai:Link
First off, thank you for considering contributing to Loc.ai! We believe that the best infrastructure is built together, and we value every bug report, feature request, and pull request.
## How to Contribute
- Fork the repository to your own GitHub account.
- Create a branch for your feature or fix (git checkout -b feature/amazing-feature).
- Commit your changes (git commit -m 'Add some amazing feature').
- Push to the branch (git push origin feature/amazing-feature).
- Open a Pull Request against our main branch.
# ⚖️ Contributor License Agreement (CLA)
To ensure we can continue to defend the project and offer it under our licensing model, we require all contributors to sign a Contributor License Agreement (CLA).
You do not need to print or mail anything. When you open a Pull Request, a bot will comment with a link. You simply need to click the link and authorize the agreement via GitHub.
## Why do we need a CLA?
The CLA ensures that Loc.ai Ltd has the necessary legal rights to redistribute your contributions. Because we use a Business Source License (BSL) that converts to Apache 2.0, we need the right to re-license your code under both of these terms (and any future terms we may need to adopt to protect the project).
## The Agreement (Summary)
By signing the CLA, you agree to the following:
Copyright Assignment: You assign the copyright of your contribution to Loc.ai Ltd.
Grant Back: Loc.ai Ltd grants you a perpetual, irrevocable license to use your own contribution however you see fit. (We own it, but you can still use it).
Originality: You promise that the code is yours to give and doesn't violate anyone else's IP.

This summary is for convenience only. The full legal text will be presented by the CLA bot.
## Code of Conduct
Please note that this project is released with a Contributor Code of Conduct. By participating in this project you agree to abide by its terms. We are committed to making participation in this project a harassment-free experience for everyone.
